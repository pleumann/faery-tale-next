# The Faery Tale Adventure – ZX Spectrum Next port

Work in progress. The original Amiga sources in the parent directory are left untouched;
this directory holds the port.

## Build

Requirements: z88dk (`zcc` in `PATH`), Python 3 (no extra modules), for running: CSpect + mono.

```
make          # converts ../game data into build/sd/FTA and builds build/sd/fta.nex
make run      # starts CSpect with build/sd as SD card root
```

On real hardware copy the contents of `build/sd` (fta.nex and the FTA folder) to the same
directory on the SD card and start fta.nex. Data paths are relative to that directory.

## Current state (M3: hero)

Julian walks through the world as a hardware sprite (two 16x16 sprites, patterns
double buffered), with the original collision (`prox`/`proxcheck`), deflection around
obstacles, terrain effects (wading, sinking, ice) and occlusion behind trees and
buildings via the shadow masks. The camera follows like `map_adjust`. The game loop
runs at 25 Hz. Without input Julian walks a short demo path.

| Key | Action |
|---|---|
| Q/A/O/P, cursor keys (5–8), Kempston joystick | walk (8 directions) |
| R | back to the start village |
| I / K | indoor map with building / dungeon tiles |

## Layout

- `tools/` – host tools: IFF reader, asset converter, PNG previews (`build/preview`)
- `src/platform/` – Next hardware layer (MMU, IM2 interrupt, Layer 2, palette, esxDOS files)
- `src/` – game code

## Memory map

| Slot | Address | Use |
|---|---|---|
| MMU0–1 | 0000–3FFF | ROM (needed for esxDOS calls); later banked code |
| MMU1 | 2000–3FFF | temporarily: map/sector lookups (ROM restored afterwards) |
| MMU2 | 4000–5FFF | data window for paged assets |
| MMU3 | 6000–7FFF | Layer 2 write window |
| MMU4–7 | 8000–FCFF | resident code + data, stack below FD00 |
| | FD00–FEFF | IM2 vector table and interrupt jump |

Sprites: patterns 0–31 / 32–63 alternate per frame; Julian's frames pages 64–68,
shadow masks pages 61–62.

Layer 2: 16K banks 9–13 (pages 18–27), used as a 20 x 8 tile torus with hardware
scrolling (only new tile columns/rows are drawn). Region data: tiles pages 40–55,
sectors 56–59, region map + terrain page 60.

## Asset files (build/sd/FTA)

Generated by `tools/convert.py` from `../game`; all multi-byte values little-endian.
Previews of everything land in `build/preview`, generated C in `build/gen`
(`assets.h` with sizes/offsets, `narr.c/h` from `../narr.asm`).

| File | Content |
|---|---|
| TILES.DAT | 17 banks x 64 tiles, 16x32 px, 8bpp column-major (512 bytes/tile, 32K/bank) |
| SECTORS.DAT | sector tile bytes: outdoor (32K) + indoor (32K), raw |
| MAPS.DAT | region maps 128x32 sector bytes: 4 outdoor bands + indoor, raw |
| TERRA.DAT | 11 terrain tables, 4 bytes per tile, raw |
| SHADOW.DAT | 192 occlusion masks 16x32x1, raw (big-endian words) |
| SHAPES.DAT | u16 count; per set u32 offset, u8 frames, u8 wcells, u8 hcells, u8 height; frames as 16x16 cells, 256 bytes each, 8bpp, colour 31 transparent |
| SAMPLES.DAT | 6 x (u16 length, unsigned 8-bit PCM) |
| MUSIC.DAT | 28 track offsets, 84 AY periods, 64 note durations, 8 waveforms, 10 envelopes, track data |
| FONT.DAT | Amber/9: header, per-char bit offset/width/space/kern, 1bpp bitmap |
| PAGE0/WINPIC .L2/.PAL | 320x256 Layer 2 image + 32 RGB4 colours |
| P1A..P3B.BIN | intro brushes: u16 w, u16 h, row-major 8bpp |
| HISCR .TIL/.MAP/.PAL | status panel as 4bpp 8x8 tiles (with mirror flags), 80x8 map, 16 colours |

## Error codes

If a file cannot be loaded, the screen turns into the ULA display with a coloured border
and the esxDOS error number as 8 blocks (white = 1, MSB left).
